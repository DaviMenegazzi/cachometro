# Cachômetro

Aplicativo privado de fotos para duas pessoas. A primeira etapa contém câmera, captura, máscaras animadas, texto opcional e salvamento na galeria.

## Executar

```bash
npm install
npx expo start
```

Abra o QR code no Expo Go em um aparelho físico para validar câmera e galeria. A integração real com servidor e notificações está planejada em [PLANO-VPS.md](./PLANO-VPS.md).
